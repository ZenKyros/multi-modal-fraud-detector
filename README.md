# ✨ Features

## Three Analytical Pillars

| Pillar | Technology | What It Detects |
|---------|------------|-----------------|
| 🎙️ **Linguistic** | Groq Whisper API | Real-time transcription, urgency keywords, financial terminology |
| 🧠 **Behavioural** | Librosa (CPU) | Speaker dominance, volume pressure, speech-to-pause ratios |
| 🔊 **Acoustic** | Librosa (CPU) | Background noise signatures (fraud call centre vs. domestic environment) |

---

## Bayesian Fusion Engine

The system models four latent call categories:

- ✅ **Normal** — Legitimate conversation
- 🏦 **BankScam** — Financial institution impersonation
- 💻 **TechSupport** — Fake technical support scams
- 🏛️ **Government** — Government or tax authority impersonation

Features include:

- Real-time Bayesian posterior updates
- Beta-distributed likelihood modelling
- Continuous threat estimation
- Threat Index defined as:

```text
Threat Index = 1 - P(Normal)
```

where values range from **0 (safe)** to **1 (high fraud probability).**

---

## Dynamic Payoff Matrix & Nash Equilibrium

The application builds a **3×3 Defender vs. Attacker payoff matrix** using the three analytical pillars.

It computes:

- Mixed-strategy Nash equilibrium
- Defender strategy
- Attacker strategy
- Adaptive pillar weighting

The payoff matrix is visualised as an interactive heatmap with the equilibrium highlighted.

---

## Adaptive Strategy Weights

Instead of manually assigning weights,

the equilibrium strategy generated by game theory becomes the adaptive weighting applied to:

- Linguistic Analysis
- Behavioural Analysis
- Acoustic Analysis

This removes arbitrary tuning parameters and allows the system to adapt dynamically.

```text

Parallel AI Analysis
├── Linguistic Analysis

│      ├── Financial keyword detection
│      └── Urgency scoring

├── Behavioural Analysis
│      ├── Speaker dominance
│      ├── Volume pressure
│      └── Speech-to-pause ratio
│
└── Acoustic Analysis
       ├── Background classification
       ├── Noise profile
       └── Environment detection

        │

        ▼

Bayesian Fusion Engine
└── Posterior update over latent fraud categories

        │

        ▼

Threat Index
Threat Index = 1 − P(Normal)

        │

        ▼

Game Theory Engine
├── Build Defender vs Attacker payoff matrix
├── Compute Nash Equilibrium
└── Generate adaptive pillar weights

        │

        ▼

Streamlit Dashboard
├── Live transcript
├── Threat meter
├── Probability charts
├── Heatmap
└── Final fraud assessment
```

# 🚀 Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/ZenKyros/multi-modal-fraud-detector.git
cd multi-modal-fraud-detector
```

---

## 2. Backend Setup

```bash
cd backend

python -m venv venv

# Linux/macOS
source venv/bin/activate

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

---

## 3. Configure Environment Variables

Create:

```text
backend/.env
```

Add:

```env
GROQ_API_KEY=your_groq_api_key_here

CORS_ORIGINS=http://localhost:8501,http://localhost:5173

DEBUG=True
```

---

## 4. Frontend Setup

Install Streamlit dependencies:

```bash
cd ..

pip install streamlit plotly pandas requests websocket-client
```

---

# ▶️ Running the Application

## Terminal 1 — Start FastAPI Backend

```bash
cd backend

# Linux/macOS
source venv/bin/activate

# Windows
venv\Scripts\activate

python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Expected output:

```text
✅ Loaded .env

GROQ_API_KEY: ✅ Set

🧠 Bayesian Fusion Engine initialized.

INFO: Uvicorn running on http://0.0.0.0:8000
```

---

## Terminal 2 — Launch Streamlit Dashboard

```bash
streamlit run streamlit_app.py
```

Expected output:

```text
Local URL:
http://localhost:8501

Network URL:
http://192.168.x.x:8501
```

Open your browser and navigate to:

```
http://localhost:8501
```
